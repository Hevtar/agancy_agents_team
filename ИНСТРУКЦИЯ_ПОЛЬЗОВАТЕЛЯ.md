# Инструкция пользователя AI Marketing Agency

## Введение

Добро пожаловать в систему AI Marketing Agency - комплексное решение для автоматизации маркетингового агентства с использованием искусственного интеллекта. Эта инструкция поможет вам начать работу с системой.

## Предварительные требования

### 1. API ключ Polza.Ai
Вам необходим API ключ от сервиса Polza.Ai (или совместимого OpenAI-сервиса). Получить ключ можно:
- Зарегистрируйтесь на https://polza.ai
- Перейдите в личный кабинет → API Keys
- Создайте новый API ключ

### 2. Установленное ПО
- **Docker** и **Docker Compose** - для запуска инфраструктуры
- **Python 3.10+** - для работы с системой
- **Git** - для клонирования репозитория

## Установка и настройка

### Шаг 1: Клонирование репозитория
```bash
git clone https://github.com/Hevtar/agancy_agents_team.git
cd agancy_agents_team
```

### Шаг 2: Настройка переменных окружения
1. Скопируйте пример файла окружения:
```bash
cp .env.example .env
```

2. Откройте файл `.env` и добавьте ваш API ключ:
```
POLZA_AI_API_KEY=ваш_ключ_здесь
POLZA_AI_BASE_URL=https://api.polza.ai/v1  # или другой совместимый URL
DATABASE_URL=postgresql://user:password@localhost:5432/agency_db
REDIS_URL=redis://localhost:6379/0
CHROMA_DB_PATH=./chroma_db
```

### Шаг 3: Запуск инфраструктуры
```bash
cd infra
docker-compose up -d
```

Проверьте статус контейнеров:
```bash
docker-compose ps
```

Должны быть запущены:
- PostgreSQL (база данных)
- Redis (кэш и сессии)
- ChromaDB (векторная база для знаний)
- Prometheus (мониторинг)
- Grafana (визуализация метрик)

### Шаг 4: Установка зависимостей Python
```bash
# Вернитесь в корень проекта
cd ..

# Установите зависимости
pip install -r requirements.txt
```

### Шаг 5: Инициализация базы данных
```bash
python scripts/init_db.py
```

## Запуск системы

### Вариант 1: Запуск API сервера
```bash
uvicorn api.app:create_app --host 0.0.0.0 --port 8000 --reload
```

API будет доступно по адресу: http://localhost:8000

Документация API: http://localhost:8000/docs

### Вариант 2: Запуск в режиме Sandbox (рекомендуется для начала)
```bash
python examples/sandbox_demo.py
```

Этот режим позволяет протестировать систему без реальных вызовов API.

## Использование системы

### 1. Доступные агенты

Система включает 15 специализированных агентов:

#### Стратегическая команда:
- **Project Manager** - управление проектами, координация
- **Marketing Strategist** - разработка маркетинговых стратегий
- **Market Researcher** - исследование рынка и конкурентов

#### Креативная команда:
- **Content Manager** - планирование и управление контентом
- **SEO Copywriter** - создание SEO-оптимизированных текстов
- **Social Media Manager** - управление социальными сетями
- **UX Designer** - проектирование пользовательского опыта

#### Аналитическая команда:
- **Data Analyst** - анализ данных и метрик
- **SEO Specialist** - технический SEO анализ
- **Web Analytics Manager** - веб-аналитика

#### Команда автоматизации:
- **Email Marketing Manager** - email рассылки
- **PPC Specialist** - контекстная реклама
- **CRM Manager** - управление взаимоотношениями с клиентами

#### Команда контроля качества:
- **Brand Manager** - контроль соответствия бренду
- **CRO Specialist** - оптимизация конверсии
- **Customer Support Agent** - поддержка клиентов
- **Report Generator** - генерация отчетов

### 2. Рабочие процессы (Workflows)

#### Workflow 1: Интегрированная маркетинговая кампания
Запускает комплексную кампанию с участием всех необходимых агентов:

```python
from workflows.integrated_campaign import IntegratedCampaignWorkflow

workflow = IntegratedCampaignWorkflow()

campaign_params = {
    "business_goals": ["Increase brand awareness", "Generate leads"],
    "target_audience": {
        "demographics": "25-45 years old",
        "interests": ["technology", "marketing"],
        "behavior": "Active online shoppers"
    },
    "budget": 10000,
    "timeline": "3 months",
    "channels": ["social_media", "email", "search", "display"]
}

result = workflow.execute_campaign(campaign_params)
```

#### Workflow 2: Производство контента
Автоматизированный процесс создания контента от идеи до публикации:

```python
from workflows.content_production import ContentProductionWorkflow

workflow = ContentProductionWorkflow()

content_params = {
    "content_type": "blog_post",
    "topic": "Digital Marketing Trends 2024",
    "target_audience": "Marketing professionals",
    "goals": ["Educate", "Generate leads"],
    "tone": "professional yet approachable",
    "length": "1500-2000 words"
}

result = workflow.produce_content(content_params)
```

### 3. Использование через REST API

#### Получить список агентов:
```bash
curl http://localhost:8000/api/v1/agents
```

#### Запустить агента:
```bash
curl -X POST http://localhost:8000/api/v1/agents/marketing_strategist/execute \
  -H "Content-Type: application/json" \
  -d '{
    "task": "Разработай стратегию для нового продукта",
    "context": {
      "product": "SaaS платформа",
      "target": "малый бизнес",
      "budget": 5000
    }
  }'
```

#### Запустить workflow:
```bash
curl -X POST http://localhost:8000/api/v1/workflows/execute \
  -H "Content-Type: application/json" \
  -d '{
    "workflow_name": "integrated_campaign",
    "parameters": {
      "business_goals": ["Lead generation"],
      "target_audience": "B2B companies",
      "budget": 15000,
      "timeline": "6 months"
    }
  }'
```

#### Поиск в базе знаний:
```bash
curl "http://localhost:8000/api/v1/knowledge-base/search?q=SEO+оптимизация&n_results=5"
```

### 4. Мониторинг системы

#### Prometheus метрики:
Откройте http://localhost:9090 для просмотра метрик системы.

#### Grafana дашборды:
1. Откройте http://localhost:3000
2. Логин: admin, пароль: admin (измените после первого входа)
3. Импортируйте дашборды из папки `monitoring/grafana/provisioning/dashboards`

Ключевые метрики:
- Количество запросов к агентам
- Время выполнения задач
- Использование токенов
- Статус системы

## Практические сценарии использования

### Сценарий 1: Создание контент-плана на месяц
```python
from agents.content_manager import ContentManagerAgent
from agents.seo_specialist import SEOSpecialistAgent

# Инициализация агентов
content_manager = ContentManagerAgent()
seo_specialist = SEOSpecialistAgent()

# Задача для контент-менеджера
task = """
Создай контент-план на месяц для блога о цифровом маркетинге.
Целевая аудитория: владельцы малого бизнеса.
Цели: привлечение трафика, генерация лидов.
Частота: 3 статьи в неделю.
"""

content_plan = content_manager.execute(task)
print(content_plan)

# SEO оптимизация плана
seo_task = f"Проведи SEO анализ и предложи ключевые слова для следующего контент-плана: {content_plan}"
seo_recommendations = seo_specialist.execute(seo_task)
print(seo_recommendations)
```

### Сценарий 2: Анализ конкурентов
```python
from agents.data_analyst import DataAnalystAgent

analyst = DataAnalystAgent()

task = """
Проведи анализ конкурентов для SaaS платформы управления проектами.
Основные конкуренты: Asana, Trello, Monday.com.
Проанализируй:
1. Ценовые стратегии
2. Ключевые особенности
3. Сильные и слабые стороны
4. Возможности для дифференциации
"""

analysis = analyst.execute(task)
print(analysis)
```

### Сценарий 3: Настройка email кампании
```python
from agents.email_marketing_manager import EmailMarketingManagerAgent

email_manager = EmailMarketingManagerAgent()

task = """
Создай стратегию email маркетинга для запуска нового продукта.
Цели:
1. Анонс продукта
2. Образование аудитории
3. Генерация предварительных заказов

Аудитория: существующие подписчики (5000 человек)
Период: 4 недели
"""

email_strategy = email_manager.execute(task)
print(email_strategy)
```

```yaml

  marketing_strategist:
    primary_model: "gpt-4"
    fallback_model: "gpt-3.5-turbo"
    max_tokens: 4000
    
  content_manager:
    primary_model: "gpt-4"
    fallback_model: "gpt-3.5-turbo"
    max_tokens: 2000
```

## Устранение неполадок

### Проблема: Ошибка аутентификации Polza.Ai
**Решение:**
1. Проверьте правильность API ключа в `.env`
2. Убедитесь, что у ключа есть необходимые права
3. Проверьте баланс аккаунта

### Проблема: Контейнеры не запускаются
**Решение:**
```bash
# Проверьте логи
docker-compose logs

# Пересоздайте контейнеры
docker-compose down
docker-compose up -d
```

### Проблема: Медленная работа агентов
**Решение:**
1. Проверьте использование ресурсов в Grafana
2. Увеличьте лимиты токенов в `model_routing.yaml`
3. Используйте более быстрые модели для простых задач

### Проблема: Ошибки в базе данных
**Решение:**
```bash
# Пересоздайте базу данных
docker-compose down
docker volume rm agancy_agents_team_postgres_data
docker-compose up -d
python scripts/init_db.py
```

## Лучшие практики

1. **Начинайте с Sandbox режима** - тестируйте новые workflows без реальных вызовов API
2. **Используйте кэширование** - Redis значительно ускоряет повторяющиеся задачи
3. **Мониторьте использование токенов** - следите за расходами через Prometheus
4. **Сохраняйте результаты** - используйте Knowledge Base для хранения успешных кейсов
5. **Настраивайте алерты** - получайте уведомления о проблемах в Grafana
